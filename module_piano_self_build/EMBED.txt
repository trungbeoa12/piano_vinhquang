NHÚNG MODULE PIANO VÀO WEBSITE KHÁC
==================================

1) Copy nguyên folder `module_piano_self_build` vào project (vd: public/module_piano_self_build/).

2) Trên trang HTML, thêm vùng mount + đúng 1 thẻ script:

   <div id="pvq-piano-mount"></div>
   <script src="/module_piano_self_build/piano-loader.js"
           data-mount="#pvq-piano-mount" defer></script>

   (Đổi src cho khớp đường dẫn thật trên server.)
   Loader sẽ tự chèn HTML widget + CSS + JS cần thiết từ chính folder này.

3) Mở trang qua HTTP (localhost hoặc deploy).
   Piano loader hiện không còn phụ thuộc fetch partial nữa, nhưng HTTP vẫn là cách chạy an toàn nhất khi nhúng vào project thật.

Tùy chọn trên thẻ script:
- data-base="https://site.com/static/module_piano_self_build/"  — nếu script không nằm cùng folder với module
- data-no-fonts="true"  — bỏ qua Google Fonts nếu site đã import Outfit + Cormorant

Không thêm tay `js/piano/piano-practice.js`, `js/piano/piano-player.js`, `js/piano/audio-engine.js`,
`js/piano/piano-keyboard.js`, `js/data/piano-lessons.js` khi đã dùng `piano-loader.js`.

Thủ công (không dùng loader): gắn piano-lessons + audio-engine + piano-keyboard + piano-player + piano-practice,
và chèn HTML giống piano-widget.partial.html vào trang; kèm css/piano-widget.css.

Flow nhúng chuẩn hiện tại:
- Copy nguyên folder.
- Tạo một mount element.
- Gắn một script `piano-loader.js`.
- Không cần copy HTML widget ra ngoài.

Ghi chú score:
- Copy file MusicXML (`.xml` / `.musicxml` / `.mxl`) và MIDI (`.mid`) vào thư mục `assets/scores/`.
- Trên phần tử mount (ví dụ `#pvq-piano-mount`), thêm:
  - `data-pvq-score-musicxml="assets/scores/<ten-file>.xml"`
  - `data-pvq-score-midi="assets/scores/<ten-file>.mid"`
- `piano-loader.js` sẽ tự render MusicXML bằng OSMD (CDN) và tạo link tải MIDI.
- Nếu bạn không cung cấp `data-pvq-score-musicxml` thì phần score sẽ không hiển thị.
